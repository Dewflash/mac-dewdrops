# Dewdrops

Offline Mac menu bar snippet shelf for prompts, replies, notes, and reusable text.

Build the local app with:

```sh
/bin/zsh scripts/build-mac-app.sh
```

The built app appears at `build/Dewdrops.app`.

## Features

- Menu bar popover for reusable text snippets
- Search, favorites, and category filters
- Add, edit, delete, and duplicate snippets
- One-click copy through the native macOS pasteboard
- Local browser storage; no internet or server
- JSON export and import for backup
